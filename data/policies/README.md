# Company rules

Put the company rule documents here as text or Markdown files. The workers search these files to find the right answer.

Planned files:

| File | What it holds |
|---|---|
| `catalogue.md` | Mobile plans, internet boxes, options, prices |
| `contracts.md` | Commitment periods, early cancellation fees |
| `procedures.md` | Lost SIM, number transfer, unpaid bill, outage |
| `agent_guidelines.md` | The order of steps an advisor must follow |
| `faq.md` | Common questions and answers |
| `complaint_procedures.md` | How to handle each kind of complaint, and the steps that cannot be skipped |
| `compensation_grid.md` | What compensation is allowed for each complaint, and the maximum |
