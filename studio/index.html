How the virtual center works

Five agents share one case file. A sixth decides the staffing.

Every call is a CallState passed between agents by a LangGraph graph. Each agent reads it and returns only what it changes. Where money, escalation or retention offers are at stake, code rules decide and the LLM only explains.

LLM decides by reading code rules decide LLM + code model drafts, code checks
The customer opens the call with its reason, mood and real account.
The advisor understands the message (intent, complaint, leaving) and answers from the rules (RAG) and the customer file.
If it's a complaint, the graph calls the complaint specialist first: category, severity, capped compensation, escalation, ticket.
If the customer wants to leave, the retention supervisor reads the churn risk and decides on an offer.
The call ends when the customer accepts, refuses or hangs up. The reviewer grades it on 6 criteria.
The results feed the workforce manager: first-call resolution changes how many advisors are needed.
The floor manager · reinforcement learning

Every 15 minutes: how many advisors on each queue?

Too few and customers hang up, too many and the center pays idle staff. Erlang C plans the day in the morning from the forecast and never adapts. The RL agent corrects that plan during the day. The floor is a SimPy simulation calibrated on 444,448 real calls (Technion bank call center): 3 queues, 25 advisors with skills, customers who hang up after about 8 minutes.

The RL problem

PPO · Stable-Baselines3
State20 numbers: time of day; per queue customers waiting, advisors working, recent wait, the Erlang C plan, calls received vs forecast; last SLA and hang-ups. ActionCorrect the Erlang C plan by −3 to +3 advisors per queue, and switch priority on or off. RewardMinus the cost of the 15 minutes: staff pay (25 €/h) + 50 € per customer who hangs up + 8 € per call answered after 20 s. Training3 agents (seeds 0, 1, 2), 400,000 decisions each, on random days with surprise peaks. Tested on 8 scenarios × 30 days it never saw; 4 of them (dashed) unlike anything in training. RealismAn advisor called in stays at least 1 hour; changing queue takes 2 minutes. Same rules for every policy.
